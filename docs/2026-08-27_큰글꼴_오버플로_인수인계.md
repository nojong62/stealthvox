## 배경

실기기(Galaxy S25, SM-S931N)에서 화면이 깨진다는 보고. 당시 기기 설정:

```
font_scale = 1.7   (작업 후반에 1.5로 낮춤)
density    = 480 → 540 (override)
```

이 조합에서 **유효 화면 폭이 320dp**로 줄어든다. 대부분의 레이아웃이 상정하지 않는 값이다.

깨진 세 건이 전부 같은 모양이었다:

```dart
Row(children: [ Icon(...), SizedBox(...), Text("라벨") ])   // Flexible 없음
```

`Row`는 flex 없는 자식에게 폭을 무한대로 준다. `Text`가 줄바꿈을 못 해 폭을 넘긴다.

### 방법

파이썬으로 Dart 소스의 괄호를 세어 `Row(...)` 블록을 잘라내고, 그 안에
`Text`/`SelectableText`/`RichText`가 있는데 `Flexible`·`Expanded`·`FittedBox`·`Spacer`가
하나도 없는 경우를 찾았다. 문자열·주석은 지우고 센다. 중첩 `Row`는 가장 안쪽만 본다.

**스캐너 한계** — 보호 장치가 `Row` **바깥**(조상)에 있으면 못 본다. 실제로 오탐 2건이
그랬다(`chat_history_list_master:310`, `lobby_master:519` — 둘 다 `FittedBox` 안).

결과: **29건 발견 → 19곳 수정 → 재실행 시 10건 남음**(전부 제외 대상).

### 방식

라벨 `Text`를 `Flexible`로 감싸고 줄바꿈을 허용했다. **`ellipsis`는 기본으로 쓰지 않았다** —
「내 입으로 말하기」가 「내 입으로…」가 되면 안 고친 것만 못하다.

## 코덱스 쪽에 물을 것

작업 트리에 **코덱스가 한 것으로 보이는 변경 16파일**이 미커밋으로 남아 있다.
주석에 `실기기 2.0배 확인, 2026-08-27` 같은 실측 근거가 붙어 있고, **같은 오버플로
작업**이다. 즉 두 작업이 겹쳤다.

확인이 필요한 것:

1. **`account_sheet.dart`** — 코덱스가 바깥을 `SafeArea` + `SingleChildScrollView`로
   감싸며 안쪽 전체를 들여썼다. 그 안에 내 `등록 정보` `Flexible` 한 줄이 파묻혀
   헝크 분리가 불가능했다. **그래서 이 파일만 커밋에서 뺐다.** 둘 다 목적이 같으니
   합쳐 커밋해도 무방해 보인다.

2. **중복 여부** — 같은 자리를 양쪽이 손댔을 수 있다. 예:
   - `lobby_master`: 코덱스가 `labelRow`를 `Wrap`으로, 드롭다운 `itemHeight: 52 → null`
   - `chat_history_master`: 코덱스가 `녹음 중...`, `AI 재생 중...`을 `Flexible`로
   - `usage_sheet`: 코덱스가 「아직 사용 내역이 없습니다」를 `FittedBox`로
   - `routine_mode_duo`: 코덱스가 연결 문구에 좌우 여백

   문법 충돌은 없다(빌드 통과). **시각적으로 이중 처리된 곳이 있는지**는 화면을 봐야 안다.

3. **나머지 15파일** — `intro_widget`, `main.dart`, `store_widget`, `terms_agreement_sheet`,
   `duo_stage`, `billing_ticker` 등. 내용을 읽지 않았다. 무슨 작업이었는지 확인 필요.
