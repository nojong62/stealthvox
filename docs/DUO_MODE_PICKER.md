# Duo — 대화 방식 선택 팝업

초대장을 만들기 직전에 한 번 뜨는 팝업. **여기서 고른 값만이 세션 문서의
`mode`가 된다.** 한 번 정하면 그 방에서는 바뀌지 않는다.

실물은 `lib/custom_code/widgets/routine_mode_duo.dart`의
`_showHostModePicker()`이고, 아래 값은 전부 그 코드에서 옮겼다.

> ⚠️ 이 문서는 근거가 아니라 지도다. 값이 어긋나면 코드가 맞다.

---

## 1. 언제 뜨는가

호스트가 **초대 버튼(👤+)** 을 누를 때. 게스트에게는 뜨지 않는다 — 방식은
초대한 사람이 정하고, 게스트는 그 방식으로 들어온다.

같은 방에 다시 초대할 때는 **뜨지 않는다.** 저장된 `mode`를 그대로 따른다
(덮어쓰지 않는다).

---

## 2. 화면 구성 — 한 페이지

```
┌─────────────────────────────────────┐
│          대화 방식 선택               │  22pt / w800 / 가운데
│      초대할 대화 방식을 골라주세요.     │  13pt / 가운데
│                                     │
│ ┌─────────────────────────────────┐ │
│ │ 📞  직접 대화                ✔  │ │  ← 고른 칸
│ │     서로의 실제 목소리로 통화합니다.│ │
│ └─────────────────────────────────┘ │
│ ┌─────────────────────────────────┐ │
│ │ 〰️  만능 통역                ○  │ │
│ │     상대의 말을 통역 음성으로…     │ │
│ └─────────────────────────────────┘ │
│    ⓘ 상대방도 선택한 방식으로 초대됩니다.│  12pt / 가운데
│                                     │
│      취소     [ 👤+ 초대하기 ]        │  1 : 2 비율
└─────────────────────────────────────┘
```

**세로는 전부 가운데로 맞춘다.** 아이콘·글·표시가 한 줄로 읽히고, 설명이
두 줄이 되어도 아이콘만 위에 남지 않는다.

배율에 천장(1.3)을 씌워 둔다 — 글꼴을 크게 써 둔 기기에서 두 칸과 버튼이
한 화면에 안 들어와 팝업 안이 스크롤됐다(실기기 확인, 2026-08-27).

## 4. 글자는 로비 ORIGIN을 따른다

**이 팝업만 로비의 ORIGIN(대화 언어)으로 적힌다.** 초대를 만드는 사람이
실제로 말하는 언어가 그것이기 때문이다. 나머지 화면은 다른 규칙을 쓴다.

문구는 `kModePickerText`(`routine_mode_duo.dart`)에 언어별로 들어 있고,
로비가 고를 수 있는 **12개 언어를 모두 덮는다.** 모르는 값이 들어오면
영어로 떨어진다(`modePickerTextFor`).

한국어 기준:

| 키 | 글 |
|---|---|
| `title` | 대화 방식 선택 |
| `subtitle` | 초대할 대화 방식을 골라주세요. |
| `directTitle` | 직접 대화 |
| `directDesc` | 서로의 실제 목소리로 통화합니다. |
| `interpTitle` | 만능 통역 |
| `interpDesc` | 상대의 말을 통역 음성으로 들려줍니다. |
| `note` | 상대방도 선택한 방식으로 초대됩니다. |
| `cancel` | 취소 |
| `invite` | 초대하기 |

`test/mode_picker_text_test.dart`가 지킨다 — 12개 언어가 다 있는지, 칸이
비지 않았는지, 두 모드의 초대 완료 문장이 서로 다른지.

---

## 5. 고른 값이 가는 곳

```
팝업 → chosenMode → duo_sessions/{id}.mode  ("direct" | "interpreter")
```

**`chat_history` 문서에는 안 실린다.** 히스토리 쪽 모드 판별은 `room_name`
(`"Duo Connect Mode"`)으로 한다 — `_inferHistoryMode()` 참고.

취소하면 `null`이 돌아오고 초대장을 만들지 않는다.

---

## 6. 손대면 안 되는 것

- **저장 id** `direct` / `interpreter`
  (`kDuoModeDirect` / `kDuoModeInterpreter`) — 이미 만들어진 방의 분류 키다
- **다시 초대할 때 덮어쓰지 않는 규칙** — 같은 방에서 방식이 바뀌면 두
  사람이 서로 다른 방식으로 통화하게 된다
- **게스트에게 안 띄우는 것** — 눌러서 역할이 뒤집히는 경로를 없앤 것이다
