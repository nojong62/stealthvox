## 1. 문서 목적

StealthVox 앱을 처음 실행했을 때 표시되는 인트로 첫 페이지의 화면 구성,
문구, 스타일과 상호작용을 기록한다.

- 기준 스크린샷: `KakaoTalk_20260827_111909815.jpg`
- 촬영 시각: 2026-08-27 11:19
- 구현 파일: `lib/custom_code/widgets/intro_master.dart`
- 페이지 식별 키: `welcome-main`

## 2. 화면의 핵심 메시지

사용자의 실제 대화를 곧바로 복습 콘텐츠로 바꾸는 것이 StealthVox의 핵심
가치임을 첫 화면에서 전달한다.

> 말한 순간, 바로 복습으로
>
> 당신의 이야기가  
> 최고의 영어 교재가  
> 됩니다

`이야기`는 청록색에서 보라색으로 이어지는 그라데이션을 적용해 핵심 단어로
강조한다.

## 3. 화면 구성

화면은 검은색에 가까운 배경 위에 다음 순서로 배치한다.

1. 상단 브랜드 영역
   - 좌측: 음성 대화 아이콘
   - 아이콘 우측: `StealthVox` 워드마크
   - 우측 상단: 비스듬히 배치된 `AD · Duo 한국어` 프로모션 배지
2. 가치 제안 태그
   - 둥근 외곽선 캡슐
   - 문구: `말한 순간, 바로 복습으로`
3. 메인 헤드라인
   - 문구: `당신의 이야기가 최고의 영어 교재가 됩니다`
   - 3줄 구성
   - `이야기`만 청록–파랑–보라 그라데이션
4. 음성 파형
   - 청록색에서 보라색으로 이어지는 파형 그래픽
   - 말하기와 복습의 연결을 시각적으로 표현
5. 주요 행동 버튼
   - 문구: `10분 듀오 맛보기 알아보기`
   - 우측 화살표 아이콘
   - 청록–파랑–보라 그라데이션 배경
6. 로그인 진입
   - 문구: `이미 계정이 있어요`
   - 하단에 청록–보라 그라데이션 밑줄
7. 페이지 진행 상태
   - 총 2페이지
   - 첫 페이지 활성 상태는 긴 청록색 캡슐
   - 두 번째 페이지는 작은 비활성 회색 점
8. 하단 안내
   - 문구: `옆으로 밀어 계속하기`

## 4. 주요 스타일 값

| 요소 | 스타일 |
|---|---|
| 전체 배경 | 검은색 계열 |
| 본문 기본색 | `#F7F8FA` |
| 태그 글자색 | `#62D8C9` |
| 태그 테두리 | `#4BCDBD`, 약 54% 불투명도 |
| CTA 그라데이션 | `#45CDBD → #5C9DDB → #765EEB` |

| CTA 화살표 | 25px |
| 로그인 글자색 | `#B7BAC3` |

## 5. 상호작용

### Duo 프로모션 배지

- 배지 또는 주변의 확장된 터치 영역을 누르면 Duo 프로모션을 표시한다.
- 배지는 약 -45도로 회전한다.
- 워드마크 영역과 겹치지 않도록 우측 끝에 별도의 터치 영역을 둔다.

### 10분 듀오 맛보기 알아보기

- 누르면 인트로 안내 두 번째 페이지로 이동한다.
- 함수: `_goToGuidePage`

### 이미 계정이 있어요

- 누르면 인증 화면을 연다.
- 함수: `_openAuthScreen`

### 좌우 스와이프

- 옆으로 밀면 인트로 페이지를 전환한다.
- 하단의 2단계 페이지 표시가 현재 위치에 맞춰 바뀐다.

## 6. 반응형 규칙

화면 높이가 720px보다 작으면 `compact` 레이아웃을 사용한다.

- 상단과 요소 사이의 세로 여백을 줄인다.
- 가치 제안과 헤드라인 사이 여백: 기본 35px, compact 26px
- 헤드라인과 파형 사이 여백: 기본 20px, compact 16px
- 파형 영역 높이: 기본 72px, compact 58px
- CTA 위 여백: 기본 34px, compact 22px
- CTA 아래 여백: 기본 14px, compact 8px
- 페이지 표시와 하단 안내 사이 여백: 기본 17px, compact 10px

콘텐츠는 화면 높이에 맞춰 세로 공간을 배분하되, 작은 화면에서도 CTA와 로그인
동작이 잘리지 않도록 구성한다.

## 8. 구현 위치

- 브랜드·프로모션 배지: `intro_master.dart`의 웰컴 첫 페이지 상단 `Stack`
- 페이지 표시: `_buildPageIndicator`
- 맛보기 CTA: `_buildWelcomeTrialAction`
- 로그인 버튼: `_buildWelcomeLoginAction`
- 첫 페이지 본문: `_buildWelcomeStoryPage`
- 두 번째 페이지: `_buildWelcomeGuidePage`

문구나 레이아웃을 변경할 때는 기준 스크린샷과 작은 화면의 `compact` 배치를
함께 확인한다.
