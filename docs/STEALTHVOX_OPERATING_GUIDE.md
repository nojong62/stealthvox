# StealthVox 화면·사용 흐름 기준서

> **이 문서는 사용자가 현재 앱에서 보는 모습과 실제 사용 흐름을 기록한다.**
> 새 화면이나 기능을 만들거나 고칠 때, 이 문서를 기준으로 기존 형태와 비교한다.
> 내부 서버 구조나 기술 구현 설명은 꼭 필요한 파일 위치만 남기고, 여기의 중심은 항상 **사용자 화면과 경험**이다.
>
> 화면 기준 버전: `1.0.216+216`  
> 마지막 화면 정리: 2026-10-08

## 1. 이 문서를 갱신하는 규칙

코드 작업으로 사용자가 보거나 누르는 것이 바뀌면, 같은 작업에서 이 문서도 바꾼다.

- 메뉴 이름, 버튼 문구, 화면 순서, 안내 문구
- 화면에 표시되는 활성/비활성/로딩/오류 상태
- 로그인 전후에 달라지는 화면과 권한
- 새 대화 방식, 학습 방식, 결제 상품, 팝업
- 줄바꿈·여백·색처럼 화면 인상에 영향을 주는 변화

반대로 사용자가 느끼는 결과가 전혀 달라지지 않는 내부 정리만 했다면 문서를 바꾸지 않아도 된다.

새 기능을 넣을 때는 아래 형식으로 해당 메뉴에 추가한다.

```markdown
### 화면/기능 이름
- 들어오는 방법:
- 사용자가 보는 것:
- 누를 수 있는 것:
- 정상 결과:
- 로딩·실패 시 보이는 것:
- 기존 화면과 비교할 점:
- 구현 참고:
```

## 2. 앱 전체에서 지켜야 할 화면 기준

### 2.1 앱이 주는 인상

- 검정에 가까운 어두운 배경 위에 밝은 글자와 한 가지 모드 색을 사용한다.
- 중요한 제목은 크고 흰 굵은 글자, 설명은 그보다 작고 회색 글자다.
- 초록은 **Scenario Talk**, 보라는 **Circle Talk**, 파랑은 **Duo Connect**를 뜻한다.
- 청록과 보라의 그라데이션은 브랜드와 가장 중요한 행동 버튼 한 곳에만 사용한다.
- 삭제·되돌리기 어려운 행동은 붉은 계열, 비활성 상태는 회색으로 확실히 구분한다.

색과 간격의 상세 기준은 [DESIGN.md](../DESIGN.md)를 따른다.

### 2.2 언어 표시 기준

| 화면 위치 | 보여 주는 언어 |
| --- | --- |
| Intro, 로그인·가입 전 안내, 로그인 전 Duo 안내 | **휴대폰 시스템 언어** |
| 로그인 후 Lobby, 대화, 학습, Store | 사용자가 고른 앱의 대화/학습 언어 |
| 사용설명서·공통 팝업 | 화면의 로그인 전후 상태에 맞는 언어 |

로그인 전에는 사용자가 앱 언어를 아직 고르지 않았으므로, 휴대폰 시스템 언어가 우선이다. 지원하지 않는 시스템 언어는 영어로 보인다.

### 2.3 공통 상태 표시

- 누른 뒤 처리 중이면 중복으로 여러 번 눌리지 않게 한다.
- 네트워크나 AI 응답을 기다릴 때는 로딩 표시 또는 진행 문구를 보여 준다.
- 실패했을 때는 “되지 않았다”만 말하지 않고, 다시 누를 수 있는지와 이유를 보여 준다.
- 사용자가 취소했거나 앱을 나갔다고 해서 저장된 대화나 본인이 끈 공개 상태가 임의로 바뀌면 안 된다.

## 3. 앱 시작과 Intro

### 3.1 처음 보이는 Intro

**들어오는 방법:** 앱을 처음 열었거나 로그인 전 상태에서 앱을 연다.

**사용자가 보는 것:**

- 어두운 배경 위 StealthVox 로고와 브랜드 색상
- 소개 문구와 좌우로 넘기는 페이지 표시
- 로그인 또는 가입으로 갈 수 있는 버튼
- Duo 통역 게시판을 소개하는 다음 페이지

**한국어 시스템 언어의 첫 제목:**

```text
당신의 이야기가
언어가 됩니다.
```

두 줄 제목 아래에는 다음 요소와 붙어 보이지 않도록 여백이 있어야 한다.

**기존 화면과 비교할 점:**

- 첫 페이지뿐 아니라 Intro의 모든 페이지와 팝업이 시스템 언어에 맞는지 확인한다.
- 제목이 한 줄로 합쳐지거나 작은 화면에서 잘리지 않는지 확인한다.
- 한국어 제목은 위의 정확한 줄바꿈을 유지한다.

**구현 참고:** `lib/custom_code/widgets/intro_master.dart`

### 3.2 Duo 소개 페이지

**들어오는 방법:** Intro를 옆으로 넘기거나 Duo 안내 흐름으로 들어간다.

**사용자가 보는 것:**

- Duo 통역 게시판이 무엇인지 설명하는 제목과 단계별 안내
- 게시판에서 초대글을 고르고, 언어를 설정하고, 통역 대화를 하는 흐름
- 로그인 또는 게시판 보기 행동 버튼

**현재 기준:** 이 페이지의 제목·설명·버튼·3단계 안내까지 모두 휴대폰 시스템 언어로 나온다.

**기존 화면과 비교할 점:** 영어 폰에서는 한국어가 섞이지 않고, 한국어 폰에서는 버튼과 안내도 한국어인지 확인한다.

### 3.3 로그인 후 첫 안내

로그인 후에는 Lobby로 들어간다. 자신의 Duo 게시글이 아직 살아 있는 경우에는 로그인 직후 유지할지 묻는다. **유지**를 선택하면 다시 활성화되고, **종료**를 선택하면 게시글을 종료한다. 이 동작의 자세한 기준은 [7. Duo Board](#7-duo-board-공개-통역-게시판)에 있다.

## 4. Lobby: 로그인 후 첫 화면

**들어오는 방법:** 로그인 완료, 홈으로 돌아오기, 대화/학습을 마치고 나가기.

### 4.1 화면에서 보이는 것

- 상단의 `StealthVox` 로고
- 오른쪽 계정 아이콘
- 대화 언어와 학습 언어를 확인·변경하는 영역
- 상단 메뉴 `SR`, `Duo Board`, `Store`
- 대화를 시작하거나 기존 기록으로 가는 주요 영역

`SR`, `Duo Board`, `Store`는 겉모양은 탭처럼 보이지만, 한 화면 안의 토글이 아니다. 각각 다른 화면 또는 시트를 연다.

### 4.2 상단 메뉴

| 메뉴 | 사용자가 누르면 보는 것 |
| --- | --- |
| **SR** | 저장한 대화 목록과 학습으로 가는 Study Room |
| **Duo Board** | 공개된 통역 대화 초대글 목록 |
| **Store** | 남은 시간, 시간 상품, 구매 이력 |

### 4.3 언어 선택

- Chat Lang은 사용자가 실제로 말할 언어다.
- Learn Lang은 학습할 언어다.
- 사용자가 직접 바꾸기 전에는 Lobby로 돌아오거나 Store를 열어도 이전 선택이 유지된다.

### 4.4 계정 버튼

- 로그인/로그아웃과 계정 관련 메뉴를 연다.
- 로그아웃하는 순간 공개 중인 Duo 글은 다른 사람에게 보이지 않게 정리되어야 한다.

### 4.5 초대 링크로 들어온 경우

- Duo 초대 링크를 누르면 유효한 초대인지 확인한 뒤 곧바로 Duo 대화 화면으로 이동한다.
- 같은 초대가 중복으로 전달돼도 같은 방을 두 번 열지 않는다.
- 이미 끝난 초대라면 대화 화면을 열지 않는다.

**구현 참고:** `lobby_master.dart`, `account_sheet.dart`

## 5. Stealth Room: 대화 방식 선택

**들어오는 방법:** Lobby에서 새 대화를 시작하거나, Duo 초대 링크를 통해 입장한다.

### 5.1 처음 보이는 메뉴

사용자는 큰 카드 형태로 아래 대화 방식을 본다.

| 카드 | 색 | 사용자에게 보이는 목적 |
| --- | --- | --- |
| **Duo Connect** | 파랑 | 다른 사람과 통역 또는 직접 음성 대화 |
| **Circle Talk** | 보라 | 관심사 중심으로 AI와 자연스럽게 대화 |
| **Scenario Talk** | 초록 | 정한 상황과 AI 역할로 역할 대화 |

아래 또는 주변 메뉴에는 Store, 사용설명서, 계정, Study Room으로 갈 수 있는 동선이 있다.

### 5.2 공통 종료 기준

- 사용자가 나가면 지금까지의 대화가 저장 가능한 상태로 마무리된다.
- 시간이 끝나더라도 사람이 말하는 한 턴이나 AI 응답을 중간에서 잘라 저장하지 않는다.
- 저장 후에도 필요한 경우 최근 맥락을 이어 같은 화면에서 대화를 계속할 수 있다.

**기존 화면과 비교할 점:** 세 카드의 이름·순서·색상 의미가 바뀌면 이 표와 관련 설명을 함께 고친다.

**구현 참고:** `lib/custom_code/widgets/stealth_room_master.dart`

## 6. AI 대화 화면

### 6.1 Circle Talk

**들어오는 방법:** Stealth Room에서 보라색 `Circle Talk` 카드를 누른다.

**사용자가 보는 것:**

- Circle Talk 제목과 짧은 설명
- 대화하고 싶은 관심사 또는 서클을 정하는 입력/선택 영역
- 추천을 받아 볼 수 있는 동선
- 대화 시작 뒤에는 AI와 주제 중심으로 주고받는 말풍선과 음성 입력 상태

**정상 결과:** 선택한 관심사에 맞춰 AI가 자연스럽게 대화를 시작하고, 대화는 Study Room에 저장된다.

**기존 화면과 비교할 점:** 관심사 입력이 비어 있을 때 추천이 자연스럽게 제시되는지, 설정을 마친 뒤 바로 대화가 시작되는지 확인한다.

**구현 참고:** `routine_mode_circle_talk.dart`, `circle_talk_guide.dart`

### 6.2 Scenario Talk 설정

**들어오는 방법:** Stealth Room에서 초록색 `Scenario Talk` 카드를 누른다.

**사용자가 보는 것:**

- `Scenario Talk 설정` 제목
- 상황 입력칸 — 예: “카페에서 음료 고르기”
- AI 역할 입력칸 — 예: “바리스타”
- `상황 추천` 버튼
- 직접 입력한 상황과 역할로 시작할 수 있는 행동 버튼

**정상 결과:** 사용자가 정한 상황과 AI 역할을 바탕으로 역할 대화가 시작된다.

### 6.3 상황 추천

**사용자가 누르면:** 상황과 AI 역할의 추천값을 받아 입력칸에 넣어 준다.

**로딩·실패 시:**

- 추천을 기다리는 동안 중복 요청이 쌓이지 않게 한다.
- 일시적인 통신/AI 응답 실패는 다시 누를 수 있어야 한다.
- 실패 안내에는 다음 점검에 도움이 되는 오류 코드가 남고, 사용자에게는 다시 시도 행동이 보인다.
- 추천이 한 번 실패했다고 입력한 내용이 지워지면 안 된다.

### 6.4 Scenario Talk 중 발화 정정

**사용자가 보는 것:** 본인이 말한 문장과 AI의 반응이 이어진다. 음성 인식이 분명히 잘못 들은 부분은 문맥과 실제 소리를 근거로 정돈될 수 있다.

**지켜야 할 기준:**

- 사용자가 실제로 한 말을 더 그럴듯한 문장으로 바꾸거나 내용을 요약하지 않는다.
- 정정 작업이 잠시 늦어져도 “어떻게 해야 할지 모르는 상태”처럼 멈춰 있으면 안 된다.
- 형식이 불완전하거나 일시적으로 실패하면 자동 재시도 또는 사용자가 다시 시도할 길이 있어야 한다.
- 정정 실패가 이후 대화를 막지 않는다. 사용자가 다시 말하면 정상 진행할 수 있어야 한다.

**구현 참고:** `routine_mode_scenario_talk.dart`, `scenario_talk_guide.dart`

## 7. Duo Board: 공개 통역 게시판

**들어오는 방법:** Lobby 상단의 `Duo Board`, Intro의 Duo 안내 버튼.

### 7.1 처음 보이는 게시판

화면 아래에서 올라오는 시트 형태의 게시판이다. 사용자는 여러 개의 초대 카드를 본다.

각 카드에는 보통 다음 정보가 보인다.

- 대화 주제
- 원래 대화 언어(`Orig.`와 언어 코드/표시)
- 현재 참여 가능한지 보여 주는 상태 표시
- 내 글이라면 활성/비활성 상태와 삭제 행동
- 번역된 주제인 경우 `Powered by Google Translate` 표시

게시판의 제목과 안내 문구는 화면의 언어 기준에 맞게 보여야 한다.

### 7.2 다른 사람의 초대글

**사용자가 하는 일:** 마음에 드는 주제를 눌러 참여를 요청한다.

**정상 결과:**

1. 작성자에게 참여 요청이 전달된다.
2. 작성자가 수락하면 Duo 대화 화면으로 들어간다.
3. 대화가 시작된 글은 다른 사람이 동시에 들어오지 못하게 잠시 막히거나 종료된다.

**사용자에게 보여야 할 상태:**

- 지금 참여할 수 있는 글은 활성 상태로 보인다.
- 작성자가 자리를 비웠거나 이미 다른 사람과 연결 중이면 참여할 수 없는 상태로 보인다.
- 요청 중에는 여러 번 요청하지 못하게 하고, 취소·거절·시간 초과를 구분해 안내한다.

### 7.3 내 초대글을 올렸을 때

회원이 자신의 Duo 대화방을 바탕으로 주제를 올리면, 본인 카드가 게시판에 나타난다.

- 처음 올린 직후 서버가 공개를 확인하면 **활성** 상태여야 한다.
- 본인이 보는 카드도 서버가 확인한 공개 상태를 표시한다. 로그인 복원 중에는 확인 전까지 비활성으로 보일 수 있다.
- 주제, 원래 언어, 활성 표시, 삭제/상태 변경 행동이 한 카드에서 명확히 보여야 한다.

### 7.4 로그인 후 게시글 유지 확인

자기 게시글이 남아 있는 채로 다시 로그인하면, 앱은 게시글을 유지할지 묻는 팝업을 표시한다.

- **유지**를 선택하면 내 글이 다시 공개되어 다른 사람이 참여 요청할 수 있다. **종료**를 선택하면 게시글이 종료된다.
- **유지** 선택 후 일시적인 통신 실패가 나면 같은 선택으로 다시 시도한다. 질문을 반복하지 않으며 서버가 공개 상태를 확인하기 전에는 활성으로 잘못 표시하지 않는다.
- 같은 로그인 중 내가 직접 **비활성화**한 글은 다시 자동으로 켜지지 않는다.
- 로그아웃으로 숨겨진 글은 다음 로그인에서 유지 여부를 다시 묻는다.
- **유지**를 선택하면 앱이 로그인 상태와 호스트 접속 상태를 확인한 뒤 내 글을 다시 공개한다. 공개 확인이 끝날 때까지는 내 카드가 잠시 비활성으로 보일 수 있다.
### 7.5 활성화/비활성화 버튼의 약속

이 부분은 가장 엄격하게 지켜야 하는 사용자 약속이다.

| 사용자가 한 행동 | 카드에 보여야 하는 결과 |
| --- | --- |
| 로그인 후 | 게시글 유지 여부를 묻고, 유지 선택 후 다시 활성화 |
| 내 글에서 **비활성화** 누름 | 즉시 비활성 표시, 다른 사람에게 공개되지 않음 |
| 비활성 상태에서 잠시 기다림 | 1초 뒤나 앱 상태 변화 뒤에 자동으로 다시 활성화되지 않음 |
| 같은 로그인 중 **다시 활성화** 누름 | 다시 활성 표시와 공개 상태 |
| 로그아웃 | 공개 상태가 정리됨 |
| 다음 로그인 | 내 글의 유지 여부를 다시 묻고 선택에 따라 공개 또는 종료 |

다른 사람의 초대를 받아 대화할 때에는 내 글이 잠시 숨을 수 있다. 그 대화가 끝난 뒤에는 **내가 직접 꺼 둔 글은 다시 켜지지 않고**, 초대 때문에 잠시 숨겼던 글만 복구할 수 있다.

### 7.6 게시판 안내 문구

- 공개 Duo 초대는 언어 연습용 대화다.
- 게시한 주제와 크게 관계없는 이야기, 욕설이나 상대를 불쾌하게 할 표현은 피하도록 안내한다.
- 대화 기록은 Study Room에 저장되며 이후 연습 자료로 쓸 수 있음을 설명한다.

**기존 화면과 비교할 점:** 카드에서 내 글과 다른 사람 글의 활성 상태가 반대로 보이지 않는지, 수동 비활성 뒤 자동으로 켜지지 않는지, 작은 화면에서 주제와 상태가 겹치지 않는지 확인한다.

**구현 참고:** `duo_board_sheet.dart`, `duo_board_host_presence.dart`, `firebase/functions/duo_board.js`

## 8. Duo Connect 대화 화면

### 8.1 통역 Duo

**들어오는 방법:** Duo Board 요청이 수락되었거나, Duo Connect에서 통역 방식으로 시작한다.

**사용자가 보는 것:**

- 상대와 연결된 대화 화면
- 내 말과 상대 말이 구분된 말풍선
- 서로 다른 언어일 때, 상대 발화의 통역 문장과 음성 재생
- 마이크가 듣는 중인지, AI가 말하는 중인지 알 수 있는 상태
- 통화/대화 종료 행동

**사용자가 기대하는 결과:** 각자는 자기 언어로 말해도 자연스럽게 대화할 수 있다. 내 말을 내 기기에서 다시 읽어 주어 다음 말을 막지 않는다.

### 8.2 Direct Voice Call

**들어오는 방법:** Duo Connect에서 직접 통화 방식으로 시작한다.

**사용자가 보는 것:**

- 실제 상대 음성을 듣는 통화 화면
- 통화 중 기록되는 전사문
- 종료 후 Study Room에서 다시 볼 수 있는 대화 기록

**기준:** 실제 사람이 말한 짧은 반응, 인사, 동의, 거절, 자기 수정도 기록에서 함부로 사라지지 않아야 한다. 명백한 기계 중복이나 실제 음성이 없는 노이즈만 정리 대상이다.

### 8.3 통화 중 문제가 생겼을 때

- 음성 인식, 통역, 음성 재생 중 지연 또는 실패가 나면 사용자가 어떤 단계에서 문제가 났는지 알 수 있어야 한다.
- 다시 시도할 수 있는 경우 버튼이나 안내가 있어야 한다.
- 일시 실패가 통화 전체를 영구히 멈추게 하면 안 된다.
- 음성 인식 보정이 실패해도 기존 문장을 빈 내용으로 바꾸면 안 된다.

**구현 참고:** `routine_mode_duo.dart`, `lib/custom_code/services/duo_*.dart`

## 9. Study Room (SR): 저장한 대화와 학습

**들어오는 방법:** Lobby의 `SR`, Stealth Room의 Study Room 메뉴, 대화를 끝낸 뒤.

### 9.1 대화 목록

**사용자가 보는 것:** 저장된 대화방 목록과 각 대화의 제목/기본 정보.

**사용자가 할 수 있는 것:**

- 대화를 열어 내용 확인
- 필요하면 대화 제목 또는 상대 표시를 수정
- 더 이상 필요 없는 기록을 삭제
- 특정 문장이나 대화를 보관

대화의 언어 정보는 그 대화를 시작한 당시 기준으로 유지되어야 한다. 나중에 Lobby의 언어를 바꿔도 과거 대화가 다른 언어 대화처럼 보이면 안 된다.

### 9.2 대화 정리와 확정

- 사용자는 대화 내용을 검토하고, 필요하면 본인이 말한 문장을 수정할 수 있다.
- 저장/취소/최종 확정 행동이 분명히 나뉘어야 한다.
- 최종 확정 전에는 실수로 눌러도 되돌릴 수 있는 안내가 있어야 한다.
- Keepers에 보관한 문장은 같은 문장이 중복 저장되지 않게 한다.

### 9.3 학습 방식 선택

대화에서 학습을 시작하면 아래 선택지가 보인다.

| 화면 표기 | 사용자 관점의 목적 |
| --- | --- |
| **PRACTICE** | 역할을 나누어 대화를 다시 연습 |
| **Clear & Easy / MY SPEECH** | 내 말의 흐름을 더 또렷하게 듣고 말하기 연습 |
| **Natural & Sharp / NATIVE ENGLISH** | 더 자연스러운 원어민식 표현을 듣고 연습 |

### 9.4 연습 화면

- 듣기, 따라 말하기, 에코잉/쉐도잉, 구간 선택, 녹음과 재생을 사용한다.
- 생성 중이면 생성 중임을, 자료가 없으면 이유를, 실패하면 다시 시도 방법을 보여 준다.
- 긴 문장이나 선택한 구간이 화면 밖으로 사라지지 않게 현재 연습 위치가 보인다.
- 종료하면 학습 선택 화면 또는 기록 화면으로 자연스럽게 돌아간다.

**기존 화면과 비교할 점:** 새 학습 방식을 넣을 때 기존 세 카드의 위계·색상·생성/실패 표기를 깨지 않는지 확인한다.

**구현 참고:** `chat_history_list_master.dart`, `chat_history_master.dart`

## 10. Store: 시간 상품과 구매 이력

**들어오는 방법:** Lobby 또는 Stealth Room의 `Store`.

### 10.1 화면에서 보이는 것

- 남은 대화 시간
- 시간 단위 상품 카드
- Google Play 기준의 현지 통화 가격
- 구매 이력으로 가는 행동
- 이용 약관/개인정보 관련 링크

현재 상품 표시는 다음과 같다.

| 상품 | 화면 표기 |
| --- | --- |
| 10분 | Trial |
| 1시간 | Standard |
| 5시간 | Best Value |
| 10시간 | Premium |

### 10.2 구매 흐름

1. 사용자가 가격이 표시된 상품 카드를 누른다.
2. Google Play 구매 화면이 열린다.
3. 성공하면 “시간을 추가하는 중”이라는 안내가 보인다.
4. 서버 반영이 되면 남은 시간이 갱신되고 성공 안내가 보인다.

### 10.3 가격 또는 반영 문제

- 실제 가격을 불러오지 못한 상품은 누를 수 있으면 안 된다.
- 구매 취소, 결제 불가, 상품을 찾지 못함은 서로 다른 안내를 보여 준다.
- 결제 성공 뒤 시간이 즉시 바뀌지 않아도 일정 시간 기다리는 안내를 보여 준다.
- 구매 이력에는 사람이 알아볼 수 있는 상품 이름과 시간 정보가 보여야 한다.

**구현 참고:** `store_master.dart`, [BILLING_ENGINE.md](BILLING_ENGINE.md)

- 일반 사용자에게는 보이지 않는다.
- 권한이 있는 경우에만 Store의 구매/시간 반영 로그를 확인할 수 있다.
