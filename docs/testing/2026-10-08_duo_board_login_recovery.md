# Duo Board 로그인 자동 복원 수정 검증

- 검증용 버전: 1.0.215+215
- 기기: Samsung SM-S931N / Android 16

## 재현

기존 1.0.214 앱에 로그인된 상태에서 Duo 게시판의 본인 글 “한국어 배울 분”이 비활성으로 표시되고 “초대글 활성화” 버튼이 노출됨을 UI 계층에서 확인했다.

## 수정

- 로그인 시 복원 동의 팝업 대신 기존 유효한 본인 글을 자동 복원한다.
- 조회 또는 복원 호출 실패 시 5초 후 재시도하고, 앱이 다시 활성화되면 재확인한다.
- RTDB presence 실패는 복원 callable을 막지 않으며, heartbeat 자체도 재시도한다.
- 같은 로그인 중 사용자가 공개 상태를 직접 바꾸면 로그인 자동 재시도를 중단한다.
- 본인 글 조회에서 종료된 글을 제외해 과거 글 10개 제한 때문에 유효한 글이 누락되지 않게 한다.
- 카드 활성 표시는 서버의 discoverable 확인을 반영한다.

## 완료한 확인

- 수정 파일 및 main.dart 정적 분석: 오류 없음. 스타일 안내 및 기존 경고는 남아 있음.
- 게시판 언어, 게시판 안내, 게스트 초대 인계 관련 기존 테스트: 41개 통과.
- release APK 빌드 성공: build/app/outputs/flutter-apk/app-release.apk

## 폰 설치 제한

기존 앱은 com.android.vending에서 설치한 Play 서명 앱이다. 출시용 로컬 APK와 Android 개발용 키로 재서명한 APK 모두 INSTALL_FAILED_UPDATE_INCOMPATIBLE로 업데이트가 거절되었다. 기존 앱의 데이터는 삭제하지 않았다.

수정본의 실제 폰 동작 확인은 기존 앱 삭제/재설치에 대한 사용자 승인 또는 Play 경유 업데이트가 필요하다. 현재까지 수정본의 폰 검증은 완료되지 않았다.
