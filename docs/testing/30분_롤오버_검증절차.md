## 0. 무엇을 검증하나

Circle Talk·Scenario Talk가 30분마다 **방에서 내보내지 않고** 저장·과금·문맥
묶음만 새로 여는 구조. 화면과 대화는 끊기지 않는다.

| 적용 | 모드 |
|---|---|
| ✅ 롤오버 | Circle Talk (`free_talk`), Scenario Talk (`roleplay`) |
| ❌ 롤오버 없음 | Step Expand — 5턴이 세션 경계다. 잔여시간 표시 버그만 고쳤다 |
| ❌ 별도 작업 | Duo — 게스트 동기화·과금 규칙이 다르다 |

핵심 불변식 두 개가 지켜지는지 보는 것이 이 검증의 전부다.

> **① `usage_logs`에 쓰는 곳은 `_closeSegment()` 하나뿐이다.**
> **② 기준선은 저장이 성공한 뒤에만 앞으로 간다.**

그리고 순서 하나.

> **정산(옛 방 id) → 새 History → 새 방 id 설정**
> 뒤집히면 직전 30분 이력이 새 방 id로 붙는다.

## 1. 선행 조건 — 이거 빠지면 검증 자체가 무의미하다

### 1.1 디버그 빌드 (30분 → 45초)

30분을 그대로 두면 경합 검증이 사실상 불가능하다. 디버그 빌드에서만 세션
길이를 줄인다. **릴리스는 이 값을 무시하고 항상 30분이다**
(`billing_ticker.dart` `kSessionSeconds`, `kDebugMode` 가드).

```powershell
flutter build apk --debug --dart-define=SESSION_SECONDS=45
```

빌드 산출물: `build/app/outputs/flutter-apk/app-debug.apk`

**코드를 안 고쳤으면 다시 빌드하지 말 것.** 폰에 있는 APK가 그대로 최신이다.

### 1.2 App Check 디버그 토큰 등록 ← 가장 자주 빠뜨리는 단계

등록이 안 되면 `deductRemainingTime`·`logUsageSession`이 전부 403으로 죽는다.
그러면 `persisted=false`만 나오고 **롤오버가 한 번도 일어나지 않아** 모든
항목이 거짓 실패로 찍힌다.

```powershell
$adb="C:\Users\u\AppData\Local\Android\Sdk\platform-tools\adb.exe"
& $adb logcat -d | Select-String "debug secret"
```

토큰은 **설치·실행 후** 찍힌다. 순서가 반대가 아니다.
Firebase Console → App Check → 앱 ⋮ → 디버그 토큰 관리에 등록.

> **앱을 재설치하면 토큰이 새로 발급된다. 매번 재등록해야 한다.**

### 1.3 계정

`nisiekorea@gmail.com` (계정 선택 화면 ③번).
테스트는 **실제 보유시간을 깎는다.** 45초 세션을 여러 번 도는 동안 대기까지
합쳐 5~10분가량 차감되고, `chat_history`에 45초마다 테스트 방이 1개씩 쌓인다.

## 3. 로그 마커 사전

| 마커 | 의미 |
|---|---|
| `[BILLING] mode=.. (session start .. newConv=true)` | 방 진입. `newConv=false`면 idle 복귀다 |
| `[BILLING-SEG] open reason=..` | 과금 구간 개방. 기준선 이동 |
| `[BILLING-SEG] rollover_due elapsed=45` | 세션 경계 도달. 신호만 세운 상태 |
| `[BILLING-SEG] close reason=.. persisted=.. reopen=..` | 구간 종료 |
| `[BILLING-SEG] close skipped .. busy=true` | 재진입 차단됨 (정상 방어) |
| `[USAGE_LOG] saved ..` | **구간당 정확히 1회여야 한다** |
| `[USAGE_LOG] skip: no deduction ..` | 차감 0 — 저장 안 함. 정상 |
| `[USAGE_LOG] error: ..` | 저장 실패. 기준선은 안 움직여야 한다 |
| `⏱️ [ROLLOVER] settled room=<옛 방>` | 정산 완료. **새 방 생성보다 먼저** |
| `📚 [HIST-NEW] chat_history 방 생성: <새 방>` | 새 History |
| `⏱️ [ROLLOVER] done room=<새 방> summary=..` | 롤오버 완료 |
| `⏱️ [ROLLOVER] settle_failed → 재시도 대기` | 정산 실패. History 안 바뀜 |

### 즉시 실패로 봐야 하는 패턴

```
[USAGE_LOG] saved ... (같은 before= 값으로 두 번)      ← 이중 정산
[BILLING-SEG] close ... persisted=false
[BILLING-SEG] open ...                                 ← 실패인데 기준선 전진
📚 [HIST-NEW] ...        (⏱️ [ROLLOVER] settled 보다 먼저)  ← 방 id 오귀속
```

## 4. 자동 항목 — 말하지 않아도 밟힌다

방에 들어가 가만히 있으면 전부 확인된다(idle pause가 60초라 45초 롤오버가 먼저).

### A. 첫 롤오버 (45초)

방 진입 → 45초 대기.

- [ ] 롤오버가 **1회만** 발생
- [ ] `⏱️ [ROLLOVER] settled` 가 `📚 [HIST-NEW]` 보다 **먼저**
- [ ] `[USAGE_LOG] saved` 1회
- [ ] `[BILLING-SEG] open` 으로 새 구간 개방
- [ ] 화면: 30초 전부터 같은 칸이 카운트다운으로, 0초에 "대화가 저장되었습니다"

### B. 반복 (100초 이상)

그대로 100초 이상 유지.

- [ ] 45초마다 롤오버 반복 (100초면 2회)
- [ ] 각 과금 구간의 `[USAGE_LOG] saved` 가 **정확히 1회**
- [ ] `chat_history` 문서가 롤오버 횟수 + 1개 생성

### C. 백그라운드 전환

롤오버 **직전**(카운트다운 5초쯤)과 **직후** 각각 홈 버튼 → 3초 이상 대기 → 복귀.

- [ ] 이중 저장 없음
- [ ] 사용시간 누락 없음 (`before`/`after` 가 구간끼리 이어져야 한다)
- [ ] 복귀 후 `[BILLING] foreground resumed` → `[BILLING-SEG] open reason=foreground`
- [ ] **복귀 후에도 30분 시계가 되감기지 않는다** (`newConv` 로그 없음)
- [ ] 카운트다운 정상 재개

> 롤오버와 백그라운드가 겹치면 `[BILLING-SEG] close skipped .. busy=true` 가
> 찍히는 것이 **정상**이다. 롤오버가 이미 그 구간을 저장했다.

### D. idle 경계

- [ ] 롤오버 대기 중에는 idle pause가 **먼저 발생하지 않는다**
      (`sessionRolloverDue` 동안 `_idleTick`이 `_idleElapsedSec`을 0으로 붙잡는다)
- [ ] 롤오버 후 새 구간에서 idle 60초가 정상적으로 다시 계산된다
- [ ] idle 복귀 시 `[BILLING] mode=.. newConv=false` — **true면 결함이다**
      (30분 시계가 되감겨 롤오버가 영영 안 온다)

## 5. 수동 항목 — 사람이 말해야 한다

마이크에 오디오를 주입할 방법이 없다(`테스트_자동화_방법.md` §2).
**Circle Talk·Scenario Talk 각각에서 45초 경계를 걸치도록** 발화한다.
카운트다운이 10초쯤일 때 말을 시작하면 경계를 넘긴다.

- [ ] 한 턴의 사용자 문장과 AI 답변이 **서로 다른 History로 갈리지 않는다**
      → `_turnInFlight` 가드가 롤오버를 턴이 끝날 때까지 미룬다
- [ ] 롤오버 완료 후 AI가 이전 문맥을 자연스럽게 잇는다
      → 다시 인사하거나 "시간이 지났네요" 하면 요약 프롬프트 결함
- [ ] `persisted=false` 뒤에 새 구간이 열리지 않는다
      → 비행기모드로 유도해 재현 가능
- [ ] 옛 방 id로 정산된 다음 새 History id가 설정된다
- [ ] 30초 카운트다운과 10초 주황 점멸이 실제 화면에서 정상
