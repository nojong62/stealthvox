현재 유저의 오리지널 글자는 딥그램 소리가 GPT4o-mini 전달되고 타겟소리와타겟글자를 만든 뒤 GPT가 역번역해서(딥그램이 전달한 오리지널(한국어) 소리를 GPT가 타겟글자로 만들고 그걸 한국어에 맞게 번역한) 오리지널 글자를 만드는 것이 맞나? 그런데 AI는 GPT가 그냥 타겟소리와글자 오리지널글자를 자신이 직접 만들면 되는데 역번역이라니? 무슨 말이야? 여기서 (오리지널은 유저가 사용하는 언어, 타겟언어는 배우려는 언어)
---------------------------------------

맞습니다. 실장님이 정리한 개념이 더 정확합니다.

제가 앞에서 **“AI도 역번역”**이라고 표현한 건 부정확했습니다. 정확히는 이렇게 구분해야 합니다.

## 1. 유저 대사 처리 구조

유저는 실제로 **오리지널 언어**, 예를 들어 한국어로 말합니다.

흐름은 보통 이렇게 됩니다.

**유저 한국어 음성 → Deepgram STT → GPT-4o-mini → 타겟 글자/타겟 음성 + 오리지널 글자**

여기서 오리지널 글자는 두 가지 방식이 가능합니다.

첫째, Deepgram이 인식한 한국어 STT 원문을 그대로 쓰는 방식.
예: “오늘 시험 몇 점 받을 것 같아?”

둘째, GPT가 타겟 문장을 만들면서 동시에 자연스럽게 다듬은 한국어 원문을 다시 만들어주는 방식.
예: Deepgram 원문이 조금 어색하면 GPT가 “오늘 시험에서 몇 점 받을 것 같아?”처럼 정리.

현재 실장님 설명처럼, 유저 쪽은 **Deepgram 원문 → GPT 타겟문 생성 → GPT가 한국어에 맞게 정리한 오리지널 글자 생성** 구조로 이해하면 됩니다.

여기서 제가 “역번역”이라고 한 것은 엄밀히 말하면 **타겟문을 다시 한국어로 번역한다**는 뜻이라기보다, 코드 함수명이 `generateCleanOriginal()` 같은 구조라서 **오리지널 표시용 문장을 따로 생성한다**는 의미에 가까웠습니다.

---

## 2. AI 대사 처리 구조

AI는 유저처럼 Deepgram 음성이 없습니다. AI는 처음부터 GPT가 문장을 직접 만듭니다.

그래서 AI는 원칙적으로 이렇게 만들어야 합니다.

**GPT-4o-mini → AI 타겟 글자 + AI 오리지널 글자 → 타겟 음성 TTS**

예를 들어 사용자가 배우는 언어가 영어이고 오리지널 언어가 한국어라면:

```text
target_text: "How do you think you did on the test?"
original_text: "시험은 어느 정도 본 것 같아?"
```

AI는 자기 대사를 만들 때 **처음부터 target_text와 original_text를 같이 만들어야 정상**입니다.

따라서 AI 쪽에서는 “역번역”이라고 부르면 헷갈립니다.
정확한 표현은 **AI bilingual response 생성**, 즉 **AI가 타겟문과 오리지널문을 동시에 생성**하는 것입니다.

---

## 3. 현재 문제의 핵심

히스토리에서 AI 두 번째 대사부터 오리지널 글자가 사라진다는 것은, AI가 화면에는 오리지널을 만들었더라도 저장할 때는 이런 식으로 들어갔을 가능성이 큽니다.

```text
translated_text: AI 타겟 글자
original_text: ''
```

즉 문제는 **AI가 오리지널을 못 만든다**가 아니라,
**AI 오리지널 글자가 히스토리 저장용 데이터에 제대로 들어가지 않는다**입니다.

---

## 4. 수정 방향을 더 정확히 바꾸면

클로드코드 지시문에서 “AI 역번역”이라는 표현은 빼는 게 좋습니다.

대신 이렇게 지시해야 합니다.

**AI 응답 생성 시 GPT가 target_text와 original_text를 동시에 반환하도록 하고, Firestore 저장 시 SYSTEM 메시지의 `translated_text`에는 target_text, `original_text`에는 original_text를 반드시 저장하라.**

만약 현재 구조상 AI가 먼저 타겟문만 만들고 나중에 오리지널문을 따로 만드는 구조라면, 그것도 가능은 하지만 표현은 이렇게 해야 합니다.

**AI target_text 확정 후, 같은 의미의 original_text를 별도 생성해 저장하라. 단, 이것은 유저 STT 기반 역번역이 아니라 AI 대사에 대한 오리지널 언어 표시문 생성이다.**

---

정리하면:

**유저:** 오리지널 음성 → Deepgram → GPT가 타겟문/오리지널 표시문 생성
**AI:** GPT가 처음부터 타겟문/오리지널문 직접 생성
**히스토리 버그:** AI `original_text`가 저장 시 빈 값으로 들어가는 문제

생활영어로는 이럴 때 이렇게 말할 수 있습니다.

**“That wording is misleading.”**
뜻: “그 표현은 오해를 부를 수 있어.”
