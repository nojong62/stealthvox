# StealthVox — 화면 설계

2026-08-26 실기기(SM-S931N, `1.0.120+120`) 스크린샷 9장에서 뽑고, **값은 전부
코드에서 확인해 적었다.** 눈으로 잰 색은 한 개도 없다.

> ⚠️ 이 문서는 근거가 아니라 **그때의 지도**다. 색과 규칙이 어긋나면 코드가
> 맞다. 고칠 때는 코드를 고치고 여기를 따라 고친다.

---

## 1. 뼈대가 되는 세 가지

**어둡다.** 배경은 검정에 가깝고, 면은 검정 위에 아주 조금 밝은 회색으로 뜬다.
색은 장식이 아니라 **뜻을 나르는 도구**로만 쓴다.

**색이 곧 모드다.** 파랑=Duo, 보라=Circle Talk, 초록=Scenario Talk. 이 짝은
로비·스텔스룸·히스토리 목록에서 한 번도 어긋나지 않는다. 아이콘 하나만 봐도
어느 모드인지 알아야 한다.

**글자는 크기로 층을 만든다.** 제목은 크고 희고 굵게, 부제는 작고 회색으로.
칸을 나누는 선이나 그림자를 거의 쓰지 않고 **크기와 밝기 차이**로만 층을 낸다.

## 2. 색

### 바탕과 면

| 이름 | 값 | 쓰는 곳 |
|---|---|---|
| 앱 배경 | `0xFF121212` | 스텔스룸·히스토리 방 전체 바탕 |
| 목록 배경 | `Colors.black` | 히스토리 목록 |
| 카드 면 | `0xFF1C1C1E` | 대화 카드, 말풍선, 연습 패널 |
| 상단 바 | `0xFF1A1A1A` | 히스토리 목록 AppBar |
| 팝업 면 | `0xFF1E1E1E` | 다른 표현 보기, 튜터링 |
| 테두리 | `0x14FFFFFF` · `0x22FFFFFF` | 구분선, 알약 테두리 |

로비만 파랑기가 도는 별도 바탕을 쓴다 — `_kLobbyBgTop 0xFF05070D` →
`_kLobbyBgMid 0xFF0B1120`, 면은 `_kLobbySurface 0xFF12151D`
(`lobby_master.dart:46`).

### 모드 색 — **한 모드에 두 톤**

| 모드 | 밝은 톤(500) | 짙은 톤(600) |
|---|---|---|
| Duo Connect | `0xFF3B82F6` | `0xFF2563EB` |
| Circle Talk | `0xFFA855F7` | `0xFF9333EA` |
| Scenario Talk | `0xFF22C55E` | `0xFF16A34A` |

**밝은 톤은 고르는 자리, 짙은 톤은 쌓인 자리에 쓴다.** 스텔스룸 모드 카드가
밝은 톤(`stealth_room_master.dart:911`), 히스토리 목록의 방 아이콘이 짙은
톤(`chat_history_list_master.dart:225`)이다. 색상은 같은 계열이라 같은 모드로
읽히고, 밝기가 달라 "지금 고르는 것"과 "지나간 것"이 갈린다.

### 학습 경로 색 (History Study)

| 경로 | 값 |
|---|---|
| PRACTICE | `0xFF4ADE80` 연두 |
| MY SPEECH | `0xFF38BDF8` 하늘 |
| NATIVE ENGLISH | `0xFFFBBF24` 노랑 |

MY SPEECH의 하늘색은 **"다른 표현 보기"와 같은 값**이다(`alt_style_popup.dart`
`kAltStyleAccent`). 둘 다 "같은 뜻을 다른 말로"를 다루는 자리라 일부러 맞췄다.

### 훈련 화면 (Echoing / Shadowing)

| 이름 | 값 |
|---|---|
| 호흡 강조 | `0xFF7DD3FC` |
| 쉐도잉 강조 | `0xFF818CF8` |
| 연습 패널 면 | `0xFF1C1C1C` |
| 연습 패널 테두리 | `0x22FFFFFF` |

### 그 밖

| 이름 | 값 | 뜻 |
|---|---|---|
| Keepers | `0xFFD97706` 앰버 | 모아 둔 문장 |
| 스타일 이름 | `0xFFB46CFF` 보라 | 팝업의 Standard/American/… 라벨 |
| 도움말 | `Colors.amberAccent` | ❓ |
| 로비 청록 | `0xFF22D3EE` | 브랜드 강조, 스텔스룸 상단 아이콘 |
| 로비 보라 | `0xFFA78BFA` | 브랜드 그라디언트 끝 |
| 경고·삭제 | `Colors.redAccent` | 되돌릴 수 없는 행동 |

### 그라디언트

- 로비 ENTER · TIME LEFT — `_kLobbyCyan → 0xFFBFDBFE → _kLobbyViolet`
  (`lobby_master.dart:582`)
- 인트로 CTA — `0xFF43CCBD → 0xFF7661EA` (`intro_master.dart:788`)

**그라디언트는 "가장 중요한 버튼 하나"에만 쓴다.** 한 화면에 둘 이상 쓰지
않는다 — 둘이 되면 어느 쪽을 눌러야 하는지가 사라진다.

## 3. 글자

| 자리 | 크기 | 굵기 | 색 |
|---|---|---|---|
| 화면 제목 | 25 | bold | 흰색 |
| 섹션 제목 | 18–19 | bold | 흰색 |
| 카드 제목 | 15–16 | bold | 모드 색 또는 흰색 |
| 본문 | 14–15 | regular | `Colors.white` / `white70` |
| 부제·설명 | 12–13 | regular | `white38` / `white54` |
| 알약 라벨 | 12 | w600 | `0xFFE7E9EE`, 자간 1.2 |

**대문자 + 넓은 자간**은 "지금 여기가 아니라 다른 곳으로 가는 문"에만 쓴다 —
`STUDY ROOM`, `ENTER`, `TIME LEFT`, `LANGUAGE`, `ORIGIN`, `TARGET`.

한글 제목은 두 줄까지 허용하고 자르지 않는다. `Scenario Talk Settings`처럼
영어 제목이 두 줄로 접히는 것도 그대로 둔다 — 줄임표보다 낫다.

## 4. 되풀이되는 부품

### 알약 (pill)

테두리만 있는 둥근 캡슐. 반지름 999, 테두리 `0x33FFFFFF`, 안쪽 여백 14×9.
`STUDY ROOM`·`SR`이 이 모양이다. **누르면 다른 화면으로 간다**는 신호다.

### 필터 칩

반지름 20, 안쪽 여백 14×8, 아이콘 16 + 글자 13. 꺼져 있으면 테두리
`Colors.white24`에 글자 `white54`, 켜지면 테두리·글자가 그 색으로 물들고
바탕에 `alpha 0.2`가 깔린다. 굵기도 normal → bold로 바뀐다.

**켜짐을 색 하나로만 알리지 않는다.** 색·굵기·바탕 셋이 함께 움직인다.

### 모드 카드 (스텔스룸)

```
┌───────────────────────────┐  ← 위쪽 4px 띠 = 모드 색
│  ●   Duo Connect       ›  │
│      초청 직접 대화        │
└───────────────────────────┘
```

카드 자체는 어두운 회색이고 **색은 위쪽 띠와 원형 아이콘에만** 들어간다.
카드를 통째로 물들이지 않는 것이 이 화면의 규칙이다 — 셋이 나란히 있어 다
물들면 눈이 쉴 곳이 없다.

### 학습 경로 카드 (History Study)

카드 전체를 옅게 물들인다(`alpha 0.12`), 테두리는 `alpha 0.65`.
제목은 대문자 + 자간 0.6, 그 아래 한 줄 설명, 있으면 본문 미리보기 3줄.
오른쪽 끝에 `›` 또는 진행 중이면 스피너.

모드 카드와 규칙이 **일부러 다르다.** 저기는 "어디로 갈까"를 고르는 자리라
담백하고, 여기는 "무엇을 연습할까"를 고르는 자리라 내용을 미리 보여 준다.

### 입력 필드

반지름 12–16, 면 `0xFF1C1C1E`, 테두리 `white24`. 라벨은 필드 **위**에 작은
회색 글자로 둔다(`상황`, `AI 역할`, `내 역할`). placeholder 안에 라벨을 넣지
않는다 — 입력하면 라벨이 사라진다.

### 버튼 셋

| 종류 | 생김새 | 쓰는 곳 |
|---|---|---|
| 채운 버튼 | 모드 색 바탕 + 흰 글자 | 그 화면의 결론 (`서클 대화 시작`) |
| 테두리 버튼 | 투명 바탕 + 모드 색 테두리·글자 | 도우미 (`서클 추천`, `상황 추천`) |
| 그라디언트 버튼 | 청록→보라 | 앱 전체의 관문 (`ENTER`, 인트로 CTA) |

## 5. 상단 바 — 자리에 뜻이 있다

**왼쪽은 나가는 문, 가운데는 지금 어디인지, 오른쪽은 도움.**

| 화면 | 왼쪽 | 가운데 | 오른쪽 |
|---|---|---|---|
| 로비 | — | `Store \| Study Room` 세그먼트 | — |
| 스텔스룸 메뉴 | 🏠 로비 · 🛒 스토어 | `STUDY ROOM` 알약 | ❓ |
| 히스토리 목록 | 🛡 스텔스룸 · 🔖 Keepers | `Study Room` 칩 | 과금 점 · ❓ |
| 히스토리 방 | `<` | 방 이름 | `SR` 알약 |
| 대화방 설정 | `<` | `SR` 알약 | 📖 가이드(모드 색) |
| Duo 대기 | `<` | 초대 아이콘 | 남은 시간(파란 알약) |

**뒤로가기(`<`)는 갈 곳이 하나뿐일 때만 둔다.** 스텔스룸 메뉴에는 로비·공부방
버튼이 이미 있어서 `<`가 뜻을 잃었고, 그 자리를 스토어에 내줬다(2026-08-26).

**과금 점**은 히스토리 목록과 연습 화면 상단에 상시로 뜬다. 초록 테두리 원
하나. 시간이 도는지 멈췄는지를 화면 어디서나 같은 자리에서 볼 수 있어야 한다.

## 6. 화면별

### 인트로 1 — 첫인상

앱 아이콘 + `StealthVox` 워드마크, 오른쪽 위에 기울어진 `AD / Duo 한 컷` 배지.
작은 알약 `말한 순간, 바로 복습으로`. 큰 제목 **당신의 이야기가 최고의 영어
교재가 됩니다** — 이 중 `이야기` 한 낱말만 청록으로 물들여 제품의 주장을
한 낱말에 건다. 가운데 파형 그림(청록→보라). 그라디언트 CTA + `이미 계정이 있어요`
텍스트 버튼. 맨 아래 페이지 점 2개.

### 인트로 2 — 체험 설명

제목 `회원가입 없이 바로 체험해 보세요`. 보라 CTA `10분 Duo 맛보기 시작 🎤`.
그 아래 카드 안에 번호(①②③) + 제목 + 설명 3단. **번호를 정사각 배지로** 두어
순서가 있는 절차임을 알린다.

### 로그인

뒤로 화살표 + 앱 아이콘. 제목 `계정으로 계속하기`. 흰 바탕 Google 버튼에
`최근` 배지 — 지난번에 쓴 방법을 기억한다는 표시. 아래 `계정 찾기`, 맨 밑
약관 문구(밑줄 링크).

### 로비

브랜드 워드마크(그라디언트) → `Store | Study Room` 세그먼트 → `TIME LEFT`
카드(그라디언트 숫자) → `LANGUAGE`(ORIGIN / TARGET 드롭다운) → 그라디언트
`ENTER` → 하단 3분할(사용 설명서 / 로그아웃 / 회원 탈퇴).

**남은 시간을 언어 설정보다 위에 둔다.** 이 앱에서 가장 자주 확인하는 값이다.

### 스텔스룸 — 대화 모드 선택

제목 `대화 모드 선택` + 모드 카드 3장. 모드가 셋뿐이라 스크롤이 없다.
(2026-08-26 Step Expand를 걷어내며 4 → 3이 됐다.)

### 대화방 설정 — Circle / Scenario

같은 뼈대에 **색과 칸 수만 다르다.**

- 공통: `<` · `SR` 알약 · 📖 가이드 / 큰 제목 두 줄 / 회색 안내 / 테두리
  추천 버튼 / 입력 칸 / 채운 시작 버튼
- Circle Talk = 보라, 입력 1칸(서클)
- Scenario Talk = 초록, 입력 3칸(상황 · AI 역할 · 내 역할)

추천 버튼을 입력 칸 **위**에 둔다 — 빈 화면에서 무엇을 적을지 모를 때 먼저
눈에 닿아야 한다.

### Duo 대기

`<` · 초대 아이콘 · 남은 시간(파란 알약 + 초록 점). 가운데 통화 화면 목업
이미지, 아래 `Waiting…`. **글자보다 그림으로 설명한다** — 상대가 무엇을 보게
되는지를 그대로 보여 준다.

### 히스토리 목록 (Study Room)

상단 바 → 필터 칩 줄(가로 스크롤) → 대화 카드 목록.
카드: 모드 색 정사각 아이콘 타일 + 날짜 제목(굵게) + 마지막 대사 한 줄(회색,
말줄임) + `›`.

**제목이 날짜인 것이 이 화면의 성격을 말한다** — 방 이름이 아니라 "언제 한
대화"로 찾는다.

## 7. 글꼴 배율

시스템 글꼴을 크게 써 둔 기기에서 짧은 라벨이 어절 중간에서 끊기던 자리가
있었다(실기기 S25, 논리 폭 320dp). 라벨만 있는 **선택 화면에서만** 배율에
천장을 씌운다.

```dart
MediaQuery.withClampedTextScaling(maxScaleFactor: 1.3, child: …)
```

- 학습 경로 고르는 화면 · 훈련 화면 — 1.3
- 스텔스룸 상단 바 — 1.2

**본문을 읽는 화면에는 천장을 씌우지 않는다.** 크게 보려고 키운 사람의 설정을
빼앗으면 안 된다.

## 8. 이름 — 화면과 저장이 다르다

| 코드·화면 | Firestore 저장 |
|---|---|
| Circle Talk | `free_talk` |
| Scenario Talk | `roleplay` / `"Roleplay Mode"` |
| Duo Connect | (없음) / `"Duo Connect Mode"` |

**표시명을 바꿔도 저장 id는 절대 바꾸지 않는다.** 과거 대화 기록의 분류
키라서, 바꾸면 이미 저장된 방이 미분류로 떨어진다. 양쪽 규칙은
`test/mode_naming_test.dart`가 지킨다.

학습 단계 이름도 마찬가지다 — 화면은 **PRACTICE · MY SPEECH · NATIVE
ENGLISH** 셋으로 통일했고, 내부에는 아직 `P3`·`_p3*` 접두가 남아 있다.

## 9. 새 화면을 그릴 때

1. 바탕은 `0xFF121212`, 면은 `0xFF1C1C1E`에서 시작한다.
2. 이 화면이 다루는 것이 **모드**면 모드 색을, **학습 단계**면 단계 색을 쓴다.
   새 색을 만들지 않는다.
3. 색은 **띠·아이콘·테두리**에 얹는다. 면 전체를 물들이는 건 학습 경로 카드
   하나뿐이다.
4. 결론 버튼은 채우고, 도우미 버튼은 테두리만 둔다. 그라디언트는 화면에 하나.
5. 상단 바는 §5 자리 규칙을 따른다. 갈 곳이 겹치는 버튼은 두지 않는다.
6. 라벨만 있는 화면이면 배율에 천장을 씌운다. 본문이 있으면 씌우지 않는다.
