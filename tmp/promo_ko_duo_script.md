# promo_ko_duo 제작 지시서 (21초) — 목표: 회원 등록

약속 하나: **친구·가족과 한국어로 수다 떤 통화가, 내 영어 교재가 된다. 짬날 때 그걸로 연습한다.**
대상: 영어(외국어)를 배우는데 교재 문장이 내 말 같지 않은 사람
배치: 위 글자 · 가운데 영상 · 아래 비움 (1080x1920, 상250/하340 비움)
소리: 통화 장면 = Flow 원음(한국어), 유저 연습 대사 = Chirp, AI·앱 소리 = 앱 자체 소리, 내레이션 = 한국어 Chirp
쓰는 기능: Duo 직접통화 → 공부방 → 다시 듣기 · 역할 바꿔 말하기 · Snap Echoing
뺀 것: 통역 통화, 초대 링크 만드는 과정, 과금 설명

## 분담
- **Google Flow (컷 1개):** 분할 화면 통화 8초, 2D 웹툰체. 위=나, 아래=친구. 한국어 대사 두 줄.
  - 나: "오늘 점심 뭐 먹었어?" / 친구: "회사 앞에 새로 생긴 국숫집 갔는데 진짜 맛있더라"
  - 프롬프트에 "0–3초 위 인물만 말함, 아래는 입 다묾 / 3–8초 아래 인물만 말함" + "no subtitles"
- **Claude Cowork (나머지):** Duo 직접통화 실제 기록 만들기(S25 + Fold 5), 공부방·연습 화면 녹화, Chirp, 합성.
  - 통화에서 위 두 줄을 실제로 주고받아 공부방에 같은 문장이 남게 한다 → 장면 1과 2가 이어진다.

## 업로드
- 제목: 친구랑 통화한 말이 영어 교재가 돼요 (제목에 # 넣지 않기)
- 설명 첫 줄: 이 영상 전용 쿠폰 코드 + "앱 안 스토어 맨 아래 '쿠폰 코드가 있으신가요?' · 1시간 무료" + Play 링크
- 고정 댓글: 설명 첫 줄과 같은 내용

## 제작 전 확인
1. 통화 녹음 목소리: 직접통화는 실제 마이크 소리를 일괄 전사한다. 폰 두 대에 실제 사람 목소리가 가장 확실하다(실장님 + 한 명). PC 스피커 Chirp 한국어가 전사되는지는 시험 1판으로 확인.
2. Snap Echoing이 Duo 기록에서도 같은 화면으로 열리는지 녹화 전 확인.
