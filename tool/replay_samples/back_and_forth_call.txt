# 시금석 ①: "어."가 동의·대답인가 단순 filler인가.
# 시금석 ⑥: 두 화자의 짧은 응답이 이어질 때 순서가 보존되는가.
#
# 볼 것 — 아래 "어."는 넷이고 **뜻이 다 다르다.**
#   1) 물음에 대한 동의        → 남아야 한다
#   2) 되묻는 소리 "어?"       → 남아야 한다
#   3) 알아들었다는 반응        → 남아야 한다
#   4) 말을 고르던 발성 "어..." → filler로 지워도 된다
# 넷을 뭉뚱그려 지우면 규칙이 너무 넓은 것이다.

HOST: 내일 갈 거지?
GUEST: 어.
HOST: 그럼 여섯 시에 보자.
GUEST: 어?
HOST: 여섯 시.
GUEST: 아, 어.
HOST: 어... 그러니까 내가 말하려던 건
HOST: 늦지 말라는 거야.
GUEST: 응.
