# 시금석 ②: 같은 화자가 끊긴 줄을 어디까지 하나로 합치는가.
# 시금석 ③: 미완성 발화에 없던 동사를 만들어 붙이는가.
#
# 볼 것 — "그래서... 내일은"은 **끝나지 않은 말이다.** 뒤에 상대 발화가 끼어
# 있으므로 다음 줄과 이어 붙일 수도 없다. "그래서 내일은 못 가."처럼 없던
# 동사가 붙어 나오면 ⑤(맥락 연결)를 너무 넓게 연 것이다.

HOST: 그래서... 내일은
GUEST: 응?
HOST: 아니야, 됐어.
GUEST: 그래서 뭐. 말해 봐.
HOST: 회사에서
HOST: 갑자기 일이 생겨서
HOST: 못 갈 것 같아.
GUEST: 아, 진짜?
